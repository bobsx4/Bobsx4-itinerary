# v0.3.0 RC2 Testing Checklist

RC2's main acceptance question is simple: **do Navigator and Explorer now feel like genuinely different experiences?**

| Area | Test | Expected result | Status |
|---|---|---|---|
| Version | Check header and Settings | Both show `v0.3.0 RC2` | To test |
| Refresh | Tap the circular Refresh button after Pages deployment | RC2 reloads without reinstalling the Home Screen app | To test |
| Navigator identity | Select Navigator and open Adventure | Navy/indigo briefing says `PLAN · OBSERVE · REPORT` | To test |
| Navigator content | Review Day 1 and Day 2 | Navigator assignments, route intelligence, Field Log, photo brief, field notes, and Navigator credential are present | To test |
| Explorer identity | Select Explorer and open Adventure | Teal/orange briefing says `SPOT · TRY · COLLECT` | To test |
| Explorer content | Review Day 1 and Day 2 | Direct missions, Road Quest, photo challenge, cool facts, My Day, and Explorer badge are present | To test |
| Content difference | Switch modes on the same day | Briefing, missions, observations, facts, photo prompt, journal labels, badge, and teaser all change | To test |
| Mobile ordering | Compare modes on iPhone | Explorer shows Road Quest near the top; Navigator shows route intelligence before Field Log | To test |
| iPad portrait | Open both modes | Two-column layout remains readable and mode styling is clear | To test |
| iPad landscape | Open both modes | Side navigation and two-column Adventure layout remain stable | To test |
| Profile separation | Add a tally/journal entry in each profile | Entries remain separate | To test |
| Badge logic | Complete 2 assignments, 3 observations, rating, and best/favourite moment | Correct mode-specific badge becomes claimable | To test |
| Memories | Claim a different badge in each profile | Active profile shows its own badge name, observations, and journal labels | To test |
| Local migration | Open Stays after update | Existing Lethbridge details and local confirmation remain | To test |
| Bottom navigation | Scroll a long Adventure page on iPhone | Menu stays fixed at the bottom and never enters page content | To test |
| Offline | Load once online, close, disable connection, reopen | Core app and saved entries open offline | To test |

## Suggested first comparison

Use **July 30**:

- Navigator begins with `Predict the Lethbridge arrival time...` and logs route evidence.
- Explorer begins with `Choose the first official road-trip song` and counts grain elevators, barns, turbines, and sunset views.

Then compare **Silverwood**:

- Navigator acts as a park analyst and tracks queues and decisions.
- Explorer focuses on new rides, splashes, reactions, and favourite attractions.
