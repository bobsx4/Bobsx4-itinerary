# Changelog

## v0.3.0 RC3.2 - 2026-07-28

### Rebuilt

- Rebuilt the complete release from the known-good v0.3.0 RC2 archive supplied by the user.
- Re-applied the intended RC3 and RC3.1 changes in a clean source tree.
- Retired the previously generated RC3 and RC3.1 deployment artifacts because their packaged runtime files were not trustworthy.

### Added

- Expandable response panels beneath assignments that require an answer.
- Structured response fields: short text, multiline text, time, number, and select choices.
- Inline answer boxes for fact and route-intelligence prompts.
- Automatic local saving of assignment and fact responses.
- Assignment answers and fact responses in the profile-specific Memories scrapbook.
- CSS-load diagnostic banner and runtime asset marker from the RC3.1 repair design.
- File hashes, clean-build provenance, release validation JSON, and post-archive integrity verification.

### Preserved

- All RC2 Navigator and Explorer differentiation for all ten days.
- Existing v3 local storage key and data schema.
- Existing hotel details, local confirmation numbers, profile names, journals, checklists, sightings, ratings, and badges.
- Fixed phone navigation, iPad layouts, refresh control, offline shell, and update check.

### Fixed

- Removed the release-packaging path that produced mismatched or corrupted runtime files.
- Bumped all app, query-string, release-manifest, and service-worker cache identifiers to RC3.2.
