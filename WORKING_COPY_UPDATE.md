# Update to v0.3.0 RC3.3 with Working Copy

GitHub from a computer is preferred. If Working Copy is required:

1. Export a backup.
2. Extract the RC3.3 ZIP in Files.
3. Delete the existing primary release files from the repository root before import.
4. Delete obsolete numbered duplicates such as `index-2.html`, `app-3.js`, and `styles-2.css`.
5. Import the **contents inside** the extracted RC3.3 folder into the repository root.
6. Commit `Road Companion v0.3.0 RC3.3 - Live Checks and Adventure scroll`.
7. Push to `origin/main`, wait for Pages, verify RC3.3, and tap Refresh in the Home Screen app.
