# Bobsx4 Road Companion v0.2.0

This release turns the original itinerary prototype into the first structured Road Companion build. The countdown is live, the version is visible, hotel addresses feed daily map links, the Spokane Valley distance is corrected, and the Sandpoint-to-Nelson day now intentionally includes the Kootenay Lake Ferry.

Exact in-app distance recalculation still requires a routing provider. v0.2.0 prepares the route endpoints so a future routing service can calculate from the saved hotels rather than manually maintained city names.
